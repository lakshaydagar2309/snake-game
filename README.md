# Snake Game

A classic Nokia-style Snake game that runs in the browser, built with HTML, CSS and JavaScript.

## Features

- Smooth snake movement on a gray checkerboard
- Score and best score (best score is saved in the browser)
- Pause, game over and restart screens
- Keyboard and touch (swipe) controls
- Works on desktop and mobile

## How to play

Open `index.html` in any browser.

| Action | Keys |
|---|---|
| Move | Arrow keys or W A S D |
| Pause / resume | Space |
| Mobile | Swipe on the board |

Eat the red dots to grow. Don't hit the walls or yourself.

## Built with

- HTML
- CSS
- JavaScript (Canvas)
